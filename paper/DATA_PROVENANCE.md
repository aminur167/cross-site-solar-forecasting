# Dataset Provenance and Reconciliation (Independent Rerun)

## Verified local source

Raw files are bundled under `data/raw/romanian_pv/` and describe two 50 kW Huawei systems in southwestern Romania, in the same regional climate. Source metadata is in the bundled dataset README and `CITATION.cff` (CC-BY-4.0). The hourly data joins inverter AC power averaged over the UTC interval `[datetime_utc, datetime_utc + 1h)` with Open-Meteo Archive historical weather and pvlib geometry at the interval midpoint. Weather values are retrospective reanalysis, not on-site pyranometer readings and not inputs available at real forecast issue time. Thus results using these columns are retrospective, not operational forecast evidence.

## Feature data funnel

The regenerated feature matrices contain Site A 12,675 rows and Site B 9,259 rows after causal feature construction, missing-target removal, 23-hour lag initialization, and requiring a contiguous next-hour target. Target daytime flags are aligned to the next-hour label using the documented `solar_elevation_deg > 5` threshold. Experiment-specific chronological cutoffs yield different training/calibration/test counts; see the generated experiment JSON and `FINAL_TEST_AND_REPRODUCIBILITY_REPORT.md`.

## Important scope limits

This is a two-site same-region study. It does not establish cross-climate, Bangladesh, global, or field-sensor generalization. The supplied weather variables are Open-Meteo estimates. The archived forecast files are distinct products and were not substituted into the experiments in this rerun.
